# Teorema 1.1


Sean $A, B, C \in \mathbb{K}^{m \times n}$.

$(A + B) + C = A + (B + C)$

**Demostración**:

$$
\begin{aligned}
((A + B) + C)_{ij} &= (A + B)_{ij} + (C)_{ij} \\
&= ((A)_{ij} + (B)_{ij}) + (C)_{ij} \\
&= (A)_{ij} + ((B)_{ij} + (C)_{ij}) \\
&= (A)_{ij} + (B + C)_{ij} \\
&= (A + (B + C))_{ij} \\
\end{aligned}
$$

Por lo tanto $(A + B) + C = A + (B + C)$.
